# مدار

تطبيق ماك مفتوح المصدر يجمع **المهام، والتقويم، والملاحظات، والدفاتر بخط اليد** في مكان واحد. بسيط، بالعربي، ويشتغل بدون إنترنت، وبدون أي ذكاء اصطناعي.

## المزايا

**المهام**
- إضافة سريعة بالكلام العادي: «اتصل بأحمد بكرة 5:30 !!» يفهم التاريخ والوقت والأولوية
- قوائم بألوان، وقوائم جاهزة: اليوم، الأيام القادمة، المكتملة

**التقويم**
- عرض شهري فيه المواعيد والمهام، مع التاريخ الهجري

**الملاحظات**
- اكتب `/` وتطلع لك كل الأوامر: عناوين، قوائم نقطية ومرقمة، مهام، قائمة منسدلة، ملاحظة بارزة، اقتباس، فاصل، كود ملوّن بلغات كثيرة، جدول، معادلات رياضية، فهرس محتويات، صفحات فرعية، روابط صفحات
- ارفع صور، فيديو، صوت، ملفات، وملفات PDF تنعرض داخل الصفحة (أو اسحبها وأفلتها)
- اربط ملفات من قوقل درايف
- تنسيق النص: عريض، مائل، تحته خط، يتوسطه خط، كود، رابط، وتظليل بستة ألوان
- ترتيب الكتل بالسحب، وأغلفة وأيقونات للصفحات، وبحث

**الدفاتر والكتب**
- الصفحات تحت بعض وتنزل بينها بالسكرول، وتكبير وتصغير ناعم بالقرص على التراكباد
- مقاسات A4 وLetter ومربع وعريض، عمودي أو بالعرض
- مخططات جاهزة: يومي، أسبوعي، شهري بالتواريخ والهجري، متتبع عادات، أهداف، اجتماع، سجل قراءة، قائمة مهام، ومخطط سنة كاملة بضغطة
- كتب PDF تنعرض بدقة الشاشة وتبقى حادة مع التكبير
- قلم حبر، قلم جاف، وفرشاة، كلها تتأثر بضغط القلم
- قلم تظليل، وممحاة للخط كامل أو لجزء منه، أو للتظليل فقط
- ارسم وثبّت لحظة ويتحول الرسم لشكل مضبوط، أو استخدم أداة الأشكال
- أداة التحديد: حدد، حرّك، كبّر وصغّر، غيّر اللون، كرر، قص والصق
- مربعات نص، صور، ومؤشر ليزر للشرح
- استورد كتب وملفات PDF واكتب عليها، من جهازك أو من قوقل درايف
- قوالب ورق: سادة، مسطّر، مسطّر ضيق، مربعات، نقاط، كورنيل، نوتة موسيقية، بستة ألوان
- شريط صور مصغرة للصفحات، وعلامات مرجعية
- تصدير صفحة كصورة أو الدفتر كامل PDF

**الحفظ والمزامنة**
- كل بياناتك ملفات على جهازك. اختر مجلد داخل قوقل درايف (أو iCloud أو OneDrive) وتتزامن لحالها بين أجهزتك

## التثبيت

1. نزّل ملف `.dmg` من صفحة [Releases](https://github.com/tuwra/madar/releases)
2. افتحه واسحب **Madar** لمجلد التطبيقات
3. التطبيق مو موقّع من Apple، فأول مرة: كليك يمين على التطبيق ← **فتح** ← **فتح**. أو شغّل هذا في الطرفية:

```bash
xattr -cr /Applications/Madar.app
```

للربط مع قوقل درايف ثبّت [Google Drive for desktop](https://www.google.com/drive/download/)، وبعدها من **الحفظ والمزامنة** داخل التطبيق اختر «احفظ في قوقل درايف».

## التطوير

```bash
npm install
npm start          # يشغّل التطبيق
npm run dist       # يبني ملف dmg في مجلد dist
```

الكود كله JavaScript عادي بدون أدوات بناء: الواجهة في `src/`، وتطبيق Electron في `electron/`. لما ترفع وسم مثل `v1.0.0`، يبني GitHub Actions ملفات dmg لأجهزة Apple Silicon وIntel ويرفقها بالإصدار.
